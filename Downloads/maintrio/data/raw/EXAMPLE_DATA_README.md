# What's real and what isn't in here

`alsda_physiology/panel.csv` is a **statistically plausible fabrication**,
generated by `scripts/make_example_panel.py` so the pipeline runs end to end
and you can see the required column layout. Nothing derived from it is
reportable. Replace it with a real ALSDA export — see `docs/DATASETS.md`.

`inspiration4/panel.csv` is **real NASA data** — a complete blood count,
comprehensive metabolic panel, and two immune/cardiovascular multiplex panels
(OSD-569, OSD-575), pulled from the live OSDR API and merged by
`scripts/build_inspiration4_panel.py`. It still has **no clinical `label`
column** — none of these files carry a deterioration diagnosis — so the loader
derives one from baseline deviation, which is circular, and every report
flags it as such. Real inputs, not-yet-real labels.

`inspiration4_osdr/` holds the raw per-accession files that panel was built
from (~330MB, gitignored). Rebuild the panel any time with:

```bash
python scripts/fetch_osdr.py --inspiration4        # refresh the manifest
python scripts/build_inspiration4_panel.py         # rebuild panel.csv
```
